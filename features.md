# Guideia — Full Feature Specification Document  
## AI-Powered Digital Learning & Safety Platform  
### Production-Level Feature Blueprint for Antigravity Implementation

---

# IMPORTANT IMPLEMENTATION NOTE

This project is currently being developed as:
- a high-fidelity prototype
- UI/UX showcase
- interaction simulation platform
- pitch-ready demonstration system

Because Antigravity cannot fully implement:
- real-time AI reasoning
- actual screenshot intelligence
- live voice conversations
- production-grade banking integrations
- realtime guardianship approval systems

the platform MUST simulate these systems professionally using:
- hardcoded flows
- pre-scripted conversations
- intelligent UI states
- fake AI outputs
- mock voice responses
- simulated app interactions
- believable assistant behavior

The final product must FEEL like:
- a real AI-powered production application
- a complete startup-ready SaaS ecosystem
- a deployable full-stack mobile/web platform

Even if some systems are simulated internally.

# ONBOARDING SYSTEM

## Emotional State Selection

2. Unsure
3. Scared

- explanation detail

---

# MODE BEHAVIOR DETAILS

## Calm Mode

UI Characteristics:
- slightly denser layout
- quicker transitions
- fewer popups
- shorter explanations

Assistant tone:
“Great! Let’s continue.”

---

## Unsure Mode

UI Characteristics:
- larger spacing
- additional hints
- slower tutorials
- more visual guidance

Assistant tone:
“You’re doing well.”

---

## Scared Mode

UI Characteristics:
- maximum simplicity
- one action per screen
- large buttons
- step-by-step overlays
- slow narration
- extra confirmations

Assistant tone:
“No rush. We’ll do this together.”
